# Visions & Personas 

- Notre Flipper est une simulation interactif, virtuel, et moderne, destiné à un public jeune et aux structures événementiels. Le système est intuitif, et facilement adaptable pour tous type de personnes des plus débutants aux plus professionels. Des maps peuvent être personnalisées par les organisateurs pour correspondre à leur événement. Des missions peuvent être assignées à chaque joueur pour ajouter une dimension de compétition et de récompense.

- PUBLIC CIBLE (PÉRIMÈTRE) : 
    - Public : 
      - unisexe
      - jeune : entre 16 et 45ans 
      - geeks, fetart, étudiants
    - Lieu événementiel :
      - festivals
      - soirées 
      - événements 
      - événement sportif
      - concerts
      - expositions
      - universités
      - lycées

- CONTRAINTES : 
    - Budget limité de 1000 euros 
    - Durée de production de 16 semaines 


# Objectifs & Non-Objectifs : 

- OBJECTIFS :
    - Ajouter un mode Multijoueur 
    - Ajouter une IA pour le mode solo : Permettre à un joueur de s’affronter contre une intelligence artificielle (IA) dans une partie solo.
    - Ajouter une option de personnalisation : Permettre aux joueurs de personnaliser leur expérience en choisissant des couleurs, des sons et des graphismes.

- NON-OBJECTIFS :
    - Mode compétition à distance : Permettre à deux flippers différents de s’affronter en comparant les scores en temps réel pour ensuite avoir un gagnant.
    - Ajouter des modes de jeux spécialisés


# USE CASES :

- USE CASE 1 :
    - ALlumer le Flipper
    - Joueur 
    - Permettre au joueur de lancer une partie en choisissant le mode de jeu : solo ou multijoueur 

- USE CASE 2 :
    - Configurer une partie 
    - Joueur 
    - Pouvoir configurer les paramètres de la partie : le nombre de joueurs, le mode de jeu, et l'ordre de passage si besoin.

- USE CASE 2++ (SOLO) :
    - Charger une partie
    - Joueur, Système
    - Pouvoir charger une partie sauvegardée et reprendre la partie à partir de là.

- USE CASE 3 :
    - Jouer une partie 
    - Joueur
    - Pouvoir jouer une partie en suivant les différentes règles et instructions données par le flipper.

- USE CASE 4 :
    - Controler les raquettes
    - Joueur 
    - Pouvoir contrôler les raquettes en utilisant les boutons. 

- USE CASE 5 :
    - Detecter les différents impacts de balle
    - Système
    - Pouvoir ajuster les points.

- USE CASE 6 :
    - Gérer les scores
    - Système
    - Pouvoir afficher et gérer les scores de chaque joueur.

- USE CASE 7 :
    - Gérer les pertes de billes
    - Système
    - Pouvoir gérer les pertes de billes et mettre à jour les points des joueurs, permet aussi de savoir si un joueur a perdu toutes ses billes : donc si il continue ou non dans la partie.

- USE CASE 8 (MULTIJOUEUR):
    - Passer au joueur suivant 
    - Joueur, Système
    - Pouvoir passer au joueur suivant et gérer son tour : continuez la partie

- USE CASE 9 (MULTIJOUEUR) : 
    - Gérer les fin de partie
    - Système
    - Pouvoir gérer la fin de partie, déterminer le gagnant et afficher les résultats.

- USE CASE 10 (SOLO): 
    - Sauvegarder une partie
    - Joueur, Système
    - Pouvoir sauvegarder la partie en cours et la reprendre ultérieurement.

- USE CASE 11 :
    - Enregistrer les scores 
    - Système
    - Pouvoir enregistrer et faire apparaitre le meilleur score effectué sur le flipper.
